# Proyecto TypeScript

Proyecto creado para aprender y practicar **TypeScript**, utilizando **Vite** como entorno de desarrollo.

## Tecnologías utilizadas

- TypeScript
- Vite
- HTML
- CSS
- Node.js
- npm

## Instalación

Clonar el repositorio:

```bash
git clone URL_DEL_REPOSITORIO
```

Ingresar a la carpeta del proyecto:

```bash
cd mi-proyecto
```

Instalar las dependencias:

```bash
npm install
```

## Ejecutar el proyecto

Iniciar el servidor de desarrollo:

```bash
npm run dev
```

Abrir en el navegador la dirección que proporciona Vite, generalmente:

```text
http://localhost:5173/
```

## Estructura del proyecto

```text
mi-proyecto/
├── public/
├── src/
│   ├── main.ts
│   ├── style.css
│   └── counter.ts
├── index.html

├── tsconfig.json

```

## Objetivo

El objetivo de este proyecto es incorporar los fundamentos de TypeScript y aprender a utilizar sus herramientas y características para desarrollar aplicaciones web.
